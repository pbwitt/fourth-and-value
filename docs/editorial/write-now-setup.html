Connect Write now

One-time administrator setup. This connects the phone button to the writer without putting private credentials in the browser. Complete the reader-submission setup first if you have not already.

1. Run this SQL in Supabase

Open your existing project → SQL Editor → New query. Copy, paste and Run.

2. Create the server connection

In Supabase, open Edge Functions → Deploy a new function → Via Editor. Name it editorial-write-now. Replace the contents of index.ts with the code below and deploy. Keep JWT verification enabled.

3. Add its GitHub credential

In GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens, create a token limited to pbwitt/fourth-and-value, with repository Actions: Read and write. Set an expiry you can maintain. No code-writing permission is needed.

In Supabase → Edge Functions → Secrets, add GITHUB_EDITORIAL_TOKEN and paste that token as its value. Never put it in a public file or send it in chat. Supabase supplies SUPABASE_URL and SUPABASE_ANON_KEY automatically.

4. Test from your phone

Open the editorial desk, select a submitted analysis idea and press Write now. It requests an extra research attempt within the weekly budget. The default result is a private draft. Reader-originated articles always require approval. GitHub queues and data refreshes can take several minutes; missing sources or exhausted budget will hold the article.

Email alerts are separate: GitHub Actions still needs RESEND_API_KEY and EDITORIAL_NOTIFY_FROM. Your notification recipient is already configured privately. Inbox counts refresh once a minute while the desk is open.
