How the NFL page works
  • What the prices implied. For each player and stat we use the main line: the line offered by the most books in our pregame snapshot (ties go to the line nearest the median). Each book’s over and under prices are converted to a no-vig probability, then averaged across books.
  • Results. Official statistics from nflverse. A player with no recorded passing, rushing or receiving usage is left out, as books usually void those bets. Pushes are shown but do not count toward rates.
  • Chance range. If every line’s no-vig probability were exactly right, the running count would stay inside the shaded band 90% of the time. “About 1 time in N” uses the same normal approximation. The band treats each bet as independent. Props from the same game tend to move together (a high-scoring game pushes many overs at once), so real swings run wider than the band shows.
  • Units. One unit on every main line at the average price across books, vig included. It shows how far results ran from the prices; it is not a strategy.
  • Prices captured. These are the last pregame prices we saved, not necessarily closing lines:
    • Not graded yet. Anytime, first and last touchdown scorers, longest rush and reception, and moneylines. Game lines begin in Week 3, when our weekly archive started saving them.

    How the NHL page works
    • What the prices implied. For each skater and stat we use the main line: the line offered by the most books in our last pregame snapshot (ties go to the line nearest the median). Each book’s over and under prices are converted to a no-vig probability, then averaged across books.
    • Results. Official NHL game and skater statistics, including overtime; a shootout counts as one goal for the winner on game lines, as books grade them. A skater with no official appearance is void and left out. Pushes are shown but do not count toward rates.
    • Chance range. If every line’s no-vig probability were exactly right, the running count would stay inside the shaded band 90% of the time. The band treats each bet as independent. Props from the same game tend to move together (a high-scoring game pushes many overs at once), so real swings run wider than the band shows.
    • Prices captured. The last snapshot we saved before each game, normally our morning refresh of the game day. These are not closing lines.
    • Units. One unit on every main line at the average price across books, vig included. It shows how far results ran from the prices; it is not a strategy.
