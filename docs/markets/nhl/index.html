How this page works
  • What the prices implied. For each skater and stat we use the main line: the line offered by the most books in our last pregame snapshot (ties go to the line nearest the median). Each book’s over and under prices are converted to a no-vig probability, then averaged across books.
  • Results. Official NHL game and skater statistics, including overtime; a shootout counts as one goal for the winner on game lines, as books grade them. A skater with no official appearance is void and left out. Pushes are shown but do not count toward rates.
  • Chance range. If every line’s no-vig probability were exactly right, the running count would stay inside the shaded band 90% of the time. The band treats each bet as independent. Props from the same game tend to move together (a high-scoring game pushes many overs at once), so real swings run wider than the band shows.
  • Prices captured. The last snapshot we saved before each game, normally our morning refresh of the game day. These are not closing lines.
  • Units. One unit on every main line at the average price across books, vig included. It shows how far results ran from the prices; it is not a strategy.
  • This page describes the market. It does not use our models and is not a pick list; for those, see NHL Top Picks.
